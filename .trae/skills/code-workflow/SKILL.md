# 代码开发工作流

## 概述

本技能提供从需求分析到代码提交的完整开发流程，每一步都会询问用户是否继续执行。

## 工作流步骤

### 阶段1：需求分析

1. **确认需求**
   - 询问用户详细需求
   - 分析需求可行性
   - 确认技术方案

2. **创建任务列表**
   - 使用 TodoWrite 创建开发任务
   - 明确每个任务的优先级

### 阶段2：代码开发

3. **代码实现**
   - 根据需求编写代码
   - 遵循项目代码风格规范

4. **更新版本信息**
   - 询问是否更新 changelog.txt
   - 询问是否更新 version.txt（版本号递增）
   - 记录本次修改内容

5. **代码检查**
   - 运行 lint 检查
   - 执行类型检查
   - 代码格式化

6. **更新项目文档**
   - 检查是否需要更新 project_structure.md
   - 更新 README.md（如有必要）
   - 同步文档与代码变更

### 阶段3：测试验证

7. **运行测试**
   - 执行单元测试
   - 验证功能正确性

8. **功能测试**
   - 手动测试核心功能
   - 记录测试结果

### 阶段4：打包构建

9. **打包构建**
   - 执行打包脚本
   - 验证打包结果

### 阶段5：代码提交

10. **代码审查**
    - 检查修改内容
    - 确认代码质量

11. **提交代码**
    - 添加修改文件
    - 编写提交信息
    - 推送到远程仓库

## 使用说明

每一步执行前都会询问：
- "是否执行此步骤？(Y/N)"

用户可以选择：
- **Y** - 执行当前步骤
- **N** - 跳过当前步骤
- **Q** - 退出工作流

## 示例

```
开始代码开发工作流...

[阶段1: 需求分析]
步骤1: 确认需求
是否执行此步骤？(Y/N) Y
请输入需求描述: ...

步骤2: 创建任务列表
是否执行此步骤？(Y/N) Y
...
```

## 注意事项

1. 请确保已安装必要的依赖
2. 确保有有效的 Git 远程仓库配置
3. 建议在执行前保存所有工作

## 快捷键

- `Y` / `y` - 执行当前步骤
- `N` / `n` - 跳过当前步骤
- `Q` / `q` - 退出工作流
